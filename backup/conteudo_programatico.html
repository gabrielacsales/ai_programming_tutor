Módulo 1 — Variáveis, Tipos de Dados e Operações

A base de qualquer algoritmo consiste em reter informações na memória do computador e manipulá-las matematicamente através de operadores e regras de precedência.

Conceitos Chave:

  • Tipagem Dinâmica: O Python identifica automaticamente tipos como inteiros (int), decimais (float) e textos (str).
  • Operadores: Uso de expressões matemáticas como exponenciação (**) e resto da divisão (%).
  • Tratamento de Saída: Formatação e arredondamento fino com a função round().

Exemplo Prático (Aprenda o Código):

# Capturando dados da lista global 'entrada' [peso, altura]
peso = entrada[0] # float
altura = entrada[1] # float

# Processamento com expressão algébrica
imc = peso / (altura ** 2)

# Saída formatada para 2 casas decimais
print(round(imc, 2))
Desafios Resolvidos neste Módulo:
1. Cálculo de IMC: Manipulação de variáveis e potências.
2. Conversor de Temperatura: Ordem de precedência aritmética com parênteses.
3. Cálculo de Desconto: Extração e cálculo de porcentagens estruturadas.

Módulo 2 — Estruturas Condicionais

Algoritmos inteligentes precisam tomar decisões baseados em dados reais. As estruturas de desvio condicional alteram o fluxo do software dependendo de testes booleanos.

Conceitos Chave:

  • Operadores Relacionais: Comparadores de igualdade (==), diferença (!=) e grandezas (>=, <=).
  • Estrutura Coesa: Uso do encadeamento if, elif e else para evitar verificações redundantes no processamento.

Exemplo Prático (Aprenda o Código):

idade = entrada[0]

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")
Desafios Resolvidos neste Módulo:
1. Verificar Maioridade: Tomada de decisão elementar.
2. Par ou Ímpar: Verificação booleana utilizando o resto da divisão por 2.
3. Desconto por Categoria: Filtros aninhados avaliando strings específicas.

Módulo 3 — Estruturas de Repetição (Loops)

Laços de repetição automatizam tarefas massivas sem a necessidade de duplicar linhas de código. Essenciais para processamento em lotes ou iterações definidas.

Conceitos Chave:

  • While (Loops Condicionais): Executa até que uma condição mapeada mude, exigindo cuidado para evitar loops infinitos.
  • For (Loops Controlados): Ideal para percorrer intervalos numéricos pré-definidos via função range().
  • Acumuladores: Padrão lógico onde variáveis incrementam seu próprio valor atual (soma += valor).

Exemplo Prático (Aprenda o Código):

# Gerando uma tabuada automatizada com o laço FOR
numero = entrada[0]
for i in range(1, 11):
    resultado = numero * i
    print(f"{numero} x {i} = {resultado}")
Desafios Resolvidos neste Módulo:
1. Contagem Regressiva: Uso do loop while decrescente.
2. Soma até o Limite: Acumulação dinâmica de valores controlados por sentinela.
3. Tabuada Completa: Aplicação do range() iterativo.

Módulo 4 — Funções e Modularização

Dividir para conquistar. Funções organizam trechos isolados de código que executam subtarefas específicas e podem ser reaproveitados em qualquer parte do sistema.

Conceitos Chave:

  • Assinatura de Funções: Declarados via palavra-chave def.
  • Escopo de Variáveis: Variáveis criadas dentro de uma função existem apenas no contexto dela.
  • Retorno versus Impressão: Compreensão do return para devolver os dados tratados para o sistema analítico.

Exemplo Prático (Aprenda o Código):

def calcular_area_retangulo(base, altura):
    area = base * altura
    return area # Devolve o valor calculado

resultado = calcular_area_retangulo(10, 5)
print(resultado)
Desafios Resolvidos neste Módulo:
1. Busca em Lista: Varredura e uso de *early return* com a função enumerate().
2. Contagem de Vogais: Iteração textual com controle de caixa baixa via .lower().
3. Lista de Status: Mapeamento em lote transformando notas em rótulos conceituais.

Módulo 5 — Estruturas de Dados Avançadas

Para lidar com volumes reais de dados, precisamos agrupá-los em estruturas de coleções como listas ordens ou dicionários complexos para consultas rápidas.

Conceitos Chave:

  • Métodos de Lista: Inclusão em execução via .append() e indexação reversa para resgatar os últimos elementos.
  • Análise Nativa: Utilização eficiente de funções integradas de alta performance como max() e min().
  • Deduplicação: Filtros baseados na cláusula not in para higienização de dados brutos.

Exemplo Prático (Aprenda o Código):

numeros = [12, 45, 7, 92, 18]

# Encontrando extremos sem a necessidade de desenhar loops manuais
maior_valor = max(numeros)
menor_valor = min(numeros)

print(f"Maior: {maior_valor} | Menor: {menor_valor}")
Desafios Resolvidos neste Módulo:
1. Encontrar Extremos: Extração rápida com algoritmos embutidos nativos.
2. Filtrar Nomes: Varredura condicional com base no comprimento de strings (len()).
3. Remover Duplicatas: Lógica de exclusão e criação de conjuntos de elementos únicos.

🏆 Desafio Final — Análise de Desempenho de Turma

O cume do projeto consiste na integração real de todos os conhecimentos adquiridos. Trabalhamos aqui com estruturas sofisticadas de nível de produção: Lista de Dicionários.

Habilidades Praticadas:

  • Desempacotamento de vetores estruturados aninhados (Acessar chaves internas dentro de loops).
  • Mapeamento estatístico com acumuladores e contadores simultâneos.
  • Retorno composto contendo múltiplos tipos de dados agregados no mesmo array final.

Código de Produção Desenvolvido:

# Estrutura complexa recebida pelo sistema
turma = entrada[0] # Lista de dicionários com chaves 'nome', 'idade', 'notas'

soma_notas_global = 0
total_alunos_adultos = 0
aprovados = []

for aluno in turma:
    # Processando idades
    if aluno['idade'] >= 18:
        total_alunos_adultos += 1

    # Calculando média individual para aprovação
    media_aluno = sum(aluno['notas']) / len(aluno['notas'])
    soma_notas_global += media_aluno

    if media_aluno >= 7.0:
        aprovados.append(aluno['nome'])

media_global = soma_notas_global / len(turma)
# Retorno unificado exigido pela plataforma
return [media_global, total_alunos_adultos, aprovados]
